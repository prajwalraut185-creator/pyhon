# Task Manager Project 📋

Yeh ek simple **Task Manager Application** hai jo Python mein likha gaya hai.

## Features ✨

✅ **Add Tasks** - Naye tasks add karein  
✅ **View Tasks** - Sab tasks dekhein  
✅ **Mark Complete** - Tasks ko completed mark karein  
✅ **Delete Tasks** - Tasks ko delete karein  
✅ **Save/Load** - Tasks ko file mein save karein  

## Project Structure 📁

```
Task_Manager_Project/
├── main.py              (Main application - yahan se chalega)
├── task.py              (Task class definition)
├── task_manager.py      (TaskManager class - sab kuch manage karta hai)
├── README.md            (Yeh file)
└── tasks.json           (Auto-generated - saved tasks)
```

## Concepts Used 🎓

- **Classes & Objects (OOP)** - `Task` aur `TaskManager` classes
- **Lists** - Tasks ko store karne ke liye
- **Dictionaries** - Task data format mein
- **File I/O** - Tasks ko JSON file mein save/load
- **Functions** - Reusable code
- **Menu-driven Interface** - User-friendly application

## Chalane ke Steps 🚀

1. Terminal mein isko folder mein jaayein:
   ```powershell
   cd Task_Manager_Project
   ```

2. Application chalayein:
   ```powershell
   python main.py
   ```

3. Menu se apni pasand ka option choose karein!
